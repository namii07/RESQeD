# ResQEd

ResQEd is a disaster preparedness and emergency response solution developed as a prototype for Smart India Hackathon 2025.

## Prototype

The current version is a UI/UX prototype designed in Figma.

[Figma Prototype](https://www.figma.com/proto/WwXMoUyMJDnwARhaKvjtAM/Untitled?node-id=3-669&t=OViE68kyeu2qYCIB-1)

React.js, JavaScript, HTML/CSS, Node.js, Express.js, MongoDB, AR/VR, REST APIs
